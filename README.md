♟️ KING'S ARENA — OOP GUI Chess Game

👑 A complete GUI-based Chess Game developed in C++ using Object-Oriented Programming (OOP) concepts and SFML graphics library.

🎯 This semester project demonstrates real-world implementation of: ✨ OOP Principles
✨ GUI Development
✨ Chess Game Logic
✨ Dynamic Memory Management
✨ Professional Software Design

🚀 FEATURES

♟️ Fully Functional Chess Board
👥 Two Player Gameplay
✅ Valid Move Detection
⚔️ Piece Capturing System
🔄 Turn-Based Gameplay
⚠️ Check Detection
👑 Checkmate Detection
🏆 Winning Screen
🖱️ Mouse Click Interaction
✨ Move Highlighting
🎨 GUI using SFML
🧠 OOP CONCEPTS USED

📦 Classes & Objects
🔒 Encapsulation
🧬 Inheritance
⚡ Polymorphism
🎭 Abstraction
🛠️ Constructors & Destructors
💾 Dynamic Memory Allocation
🛠️ TECHNOLOGIES

💻 C++
🎨 SFML 3.0.2
🖥️ Visual Studio
